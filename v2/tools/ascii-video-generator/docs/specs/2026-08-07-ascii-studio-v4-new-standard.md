# ASCII Cinematic Worlds v4 — new-standard acceptance contract

V4 is complete only when a frame remains meaningful after captions and diagram
labels are removed. The image must function as editorial illustration, cinematic
space and native ASCII simultaneously.

## Image standard

| Dimension | Required gate |
|---|---|
| Hero image | One clean, caption-free hero plate per chapter and a package contact sheet. |
| Recognizable world | Every chapter declares a non-generic world and the world vocabulary is at least 75% unique within a reel. |
| Real depth | Atmosphere, architecture, subject and foreground are separate planes with camera-dependent parallax and occlusion. |
| ASCII craft | Glyph selection accounts for local stroke direction; macro silhouette, meso contour and micro texture survive conversion. |
| Narrative light | Every world declares a light rig that changes through establish, explain and transform. |
| Metamorphosis | Every chapter completes a named conceptual transformation rather than merely crossfading. |
| Temporal coherence | Adjacent-frame difference stays inside the production window; random per-frame texture is prohibited. |
| Multi-format | Hero subject, captions, semantic labels and website signature survive true 9:16, 1:1 and 16:9 recomposition. |

## Locked visual plates

An approved plate may replace a native world source. It must be stored as a package
asset, referenced with an absolute path in the storyboard and decomposed into
luminance, contour, hero mask and depth. Missing plates fall back to the chapter's
native deterministic world; publication never depends on an unavailable network.

## Automated release gates

The verification JSON must pass cinematic worlds, four depth planes, semantic
metamorphosis, world diversity, background structure, temporal coherence, hero
plate contact sheet, codecs, captions, sound and all platform deliveries.

## Human release gates

Review both approval sheets at mobile size. Each chapter must have an immediately
recognizable silhouette, a different topology, visible depth and a final transform.
Reject any shot that could be mistaken for a generic visualizer or for another
chapter with its labels removed.
